# DSA Revision

My personal Data Structures & Algorithms revision repository.

This repository focuses on **problem-solving patterns, common templates, important problems, and mistakes** rather than lengthy theoretical notes.

## Goals

* Build strong DSA fundamentals
* Improve pattern recognition
* Practice common interview problems
* Maintain reusable code templates
* Track mistakes and weak areas
* Prepare for technical interviews and placements

## Topics

* Arrays
* Strings
* Linked Lists
* Stack & Queue
* Binary Search
* Trees & BST
* Heap / Priority Queue
* Greedy
* Graphs
* Dynamic Programming
* Trie
* DSU
* Bit Manipulation

## Revision Method

For every topic:

1. Understand the core concepts
2. Identify common patterns
3. Learn the standard templates
4. Solve representative problems
5. Record mistakes
6. Revisit difficult problems using spaced repetition
